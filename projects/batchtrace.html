Bad Batch Tracer

Every month India’s drug regulator publishes batches that failed quality testing. Bad Batch Tracer extracts them, matches them against what a hospital has already dispensed — even hand-typed or missing batch numbers — and lists exposed patients whose labs suggest harm, for clinical follow-up.

The problem

Failed-batch lists exist; nobody checks them against dispensing

CDSCO publishes “Not of Standard Quality” and spurious-drug lists as PDFs every month. Hospitals rarely cross-check them against what they have already dispensed, so exposed patients are never contacted.

System architecture

Snowflake-first, cited end to end

The team plan fixes a few principles that shape the diagram:

❄

Snowflake-first

If Snowflake can do it, do it there: AI_PARSE_DOCUMENT, AI_COMPLETE with JSON schema, Dynamic Tables, Tasks, Snowpark UDFs, Cortex Search, Semantic Views, Cortex Agents.

§

Cite, don’t claim

Every alert-derived fact shown to a user links back to source_file + page.

⚕

Clinical wording

Flags say “needs clinician review”, never a diagnosis.

$

Protect the credits

X-Small warehouses, 60 s auto-suspend, a resource monitor; parse each file once and store the result.

Matching

Exact, probable and watchlist

Batch numbers on alerts are printed; batch numbers at the pharmacy are scanned, hand-typed or missing. The matcher therefore produces tiers rather than a boolean.

alert (PDF)Metformin 500 mg · batch BT-24/0451 · mfr ACME · NSQ (dissolution)
dispensed: QRbatch BT-24/0451 → exact match
dispensed: typedbatch BT24-0451 → normalise → probable (fuzzy: JAROWINKLER / EDITDISTANCE)
dispensed: blankbatch (blank) → same product, valid window → watchlist
The data layer

Built to be scored

A synthetic hospital with a ground-truth answer key lets the matcher’s accuracy be measured instead of eyeballed. The key (data/synthetic/ground_truth/) is evaluation-only and must never be loaded into a Snowflake schema the app can read.

Validation

Seeded scenarios and automated checks

Children, kidney signal

Seeded exposure: 6 exposed patients, 3 with a signal, all children. The signal is creatinine rising above 2× baseline within 3–10 days — wording is “needs clinician review”, never a diagnosis.
